# Matrix Call for OpenClaw

This is an experimental alpha package for OpenClaw 2026.10.2. It registers a Matrix Call channel descriptor, owner-only Matrix `/matrixcall` status/dial/join/leave commands, an optional owner-authorized `matrix_call` model tool and an administrator Gateway RPC. Media requires a separately configured worker.

The source candidate `0.1.0-alpha.2` adds owner-authorized `matrix_call` model tools and `/matrixcall dial` for assistant-initiated ringing and opening speech. It requires a matching outbound-capable browser worker. This candidate has not been published. See [outbound calls](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/outbound-calls.md) for setup and current validation.

The previous public alpha.1, without outbound calling, can be installed explicitly:

```sh
openclaw plugins install clawhub:@hjyoon/openclaw-matrix-call@0.1.0-alpha.1 --accept-capabilities
```

Use a separate profile for initial setup. Review the package source/capabilities and [release assets](https://github.com/hjyoon/openclaw-matrix-call/releases) before installing; registry checks must have completed for this command to work. Enable/configure `matrix-call`, provision both workers and enroll trusted devices through the operator instructions below.

The separate portable worker implements encrypted MatrixRTC audio and optional speech services. The native package can optionally expose signed text turns through a Gateway-owned agent service and control the worker's signed media API. Installing this package alone cannot provide voice conversations. See [native worker control](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/native-worker-control.md), [native agent configuration](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/native-agent-service.md) and [public release readiness](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/release-readiness.md).

The exported agent adapter uses the public SDK ingress API, creates an independent host session for each neutral call UUID, preserves the verified Matrix caller, and propagates cancellation. It requires the host's `meta.finalAssistantVisibleText`; it fails closed when that field is absent instead of exposing ambiguous raw payloads or diagnostic text. [Installed Gateway checks](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/agent-integration.md) exercise actual SDK dispatch with a deterministic provider fixture. Optional [live model checks](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/live-model-integration.md) pass actual Korean/English inference and exact host history with an existing operator login.

The adapter dispatches delegated, tool-free turns. OpenClaw 2026.10.2 restricts authenticated owner admission to bundled or trusted official plugins; community plugin installation does not remove that restriction. Privileged tasks and general-user approvals are not implemented. The worker must never receive a Gateway operator token.

The [combined native Matrix check](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/native-matrix-integration.md) runs installed SDK dispatch and administrator controls with actual encrypted Korean/English speech in the production driver and restored browser image. Its provider text remains deterministic. [Element Call 0.28.0 validation](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/released-client-integration.md) passes encrypted Matrix chat entry, actual Korean/English model replies and independent history after leave/rejoin in standalone compatibility mode with one trusted backend. The [operator Compose check](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/operator-compose-integration.md) passes actual model replies and explicit service replacement from an empty profile using a native Linux Gateway and separate Docker browser/speech workers. Broader interoperability and sustained-call/input stability remain unverified.

Matrix chat control also requires the separately installed official Matrix messaging plugin. Send the literal `/matrixcall status`, `/matrixcall join <room-id>` or `/matrixcall leave <session-uuid>` at the beginning of a message in an isolated DM or a dedicated allowlisted control room. Configure the messaging adapter's DM session scope as `per-room`; a control room requires `requireMention: false`. Visible bot-mention prefixes before this custom command are unsupported in the pinned adapter. The calling plugin independently checks the complete Matrix sender ID against its owner policy. See [command integration evidence](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/matrix-command-integration.md).

See the repository's [implementation status](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/implementation-status.md), [agent protocol](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/agent-protocol.md), and [Matrix compatibility](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/matrix-compatibility.md).

For the experimental manual deployment, see [operator setup](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/operator-setup.md). Separate [worker image archives](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/worker-image-distribution.md) can be verified and loaded without rebuilding on the target host. The plugin archive is checked by the [pinned marketplace inspector](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/marketplace-distribution.md). Use the exact release version and compare both artifact reports before installation. Availability in a registry requires its completed publication checks; a local archive is not proof of public availability.
