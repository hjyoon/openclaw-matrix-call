# Matrix Call for OpenClaw

This is an experimental development package for OpenClaw 2026.10.2. It registers a Matrix Call channel descriptor, owner-only Matrix `/matrixcall` status/join/leave commands and an administrator Gateway RPC. Media requires a separately configured worker.

The separate portable worker implements encrypted MatrixRTC audio and optional speech services. The native package can optionally expose signed text turns through a Gateway-owned agent service and control the worker's signed media API. Installing this package alone cannot provide voice conversations. See [native worker control](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/native-worker-control.md), [native agent configuration](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/native-agent-service.md) and [public release readiness](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/release-readiness.md).

The exported agent adapter uses the public SDK ingress API, creates an independent host session for each neutral call UUID, preserves the verified Matrix caller, and propagates cancellation. It requires the host's `meta.finalAssistantVisibleText`; it fails closed when that field is absent instead of exposing ambiguous raw payloads or diagnostic text. [Installed Gateway checks](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/agent-integration.md) exercise actual SDK dispatch with a deterministic provider fixture. Real AI inference in a spoken call still needs validation.

The adapter dispatches delegated, tool-free turns. OpenClaw 2026.10.2 restricts authenticated owner admission to bundled or trusted official plugins; community plugin installation does not remove that restriction. Privileged tasks and general-user approvals are not implemented. The worker must never receive a Gateway operator token.

The [combined native Matrix check](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/native-matrix-integration.md) now runs installed SDK dispatch and administrator controls with actual encrypted Korean/English speech in the production driver and restored browser image. Its provider text remains deterministic. Released-client interoperability, actual model inference and clean operator setup still gate a calling release.

See the repository's [implementation status](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/implementation-status.md), [agent protocol](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/agent-protocol.md), and [Matrix compatibility](https://github.com/hjyoon/openclaw-matrix-call/blob/main/docs/matrix-compatibility.md).
