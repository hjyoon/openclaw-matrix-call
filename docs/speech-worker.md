# Local speech worker

The optional speech worker implements the recognition and synthesis ports without requiring a hosted account. It is separate from the Matrix browser worker and agent runtime. This package is under development; adding its audio boundary does not establish a complete speech service or client interoperability.

The engine boundary accepts mono signed PCM, 8–48 kHz, at most ten seconds. Recognition input is converted to 16 kHz using a normalized Hann-windowed sinc filter with sixteen destination-bandwidth zero crossings on either side. Native 16 kHz input is copied. Output duration is rounded to the nearest destination sample, retains at least one sample, and clamps filter overshoot to signed 16-bit range. No buffer ownership is shared with callers.

Engine WAV files use the canonical 44-byte PCM16 header. Compressed, floating-point, stereo, additional-chunk and inconsistent-length files are rejected. The synthesis adapter may explicitly enable the exact streaming length sentinels emitted by the pinned eSpeak NG CLI; this exception does not apply to arbitrary network input. Actual output bytes and duration remain bounded.

The subprocess runner executes an absolute operator-selected binary with a fixed argument vector and no shell. It passes only a UTF-8 locale, never inherited credentials or loader options. Input is copied and bounded to 320,044 bytes; stdout is capped by the adapter, and stderr is discarded with a 65,536-byte cap. Errors expose fixed codes rather than engine diagnostics. Cancellation or overflow sends SIGTERM, escalates to SIGKILL after 500 ms, and waits for the child to close before releasing the operation. The shipped engines use in-process CPU computation without helper executables.

`WhisperRecognition` invokes whisper.cpp with CPU inference, a fixed model, one to eight operator-selected threads (default two), and `auto`, `ko` or `en` recognition language. Each request gets a mode-0700 directory and mode-0600 input WAV; the directory is removed after completion or failure. Transcript output is strict UTF-8, trimmed and bounded to 16,000 characters. Requests do not share model context or transcripts.

`EspeakSynthesis` invokes eSpeak NG with plain UTF-8 text on stdin. Automatic language selection uses the Korean voice when the text contains Hangul and the English voice otherwise. Operators may fix either language and choose 80–300 words per minute (default 175). This is a lightweight CPU baseline with synthetic, non-neural voices; it does not establish natural pronunciation quality. Audio exceeding ten seconds fails rather than being silently truncated. Text and intermediate audio buffers are wiped after use. Immutable JavaScript strings cannot be reliably erased.
